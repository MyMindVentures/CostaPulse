# CostaPulse AI Agent Issue Guardrail

`AGENTS.md` remains the binding repository-wide policy source of truth.

Before implementing or proposing any new feature, every AI agent must structure the work using `.github/ISSUE_TEMPLATE/feature.md`. The issue must define the applicable database, Storage, backend, roles and capabilities, navigation and routing, pages and data, user flow, acceptance criteria, tests and definition of done.

Do not start implementation from an incomplete or unstructured feature request. Mark non-applicable sections explicitly as `No changes` instead of omitting them. Keep each issue atomic and do not implement work outside its documented scope.
